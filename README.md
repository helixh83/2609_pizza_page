# 피자봉봉 함덕 홈페이지

제주 함덕의 로컬 피자 브랜드 **피자봉봉**을 소개하는 반응형 브랜드 웹사이트입니다.

## 구성

- 제주 로컬 식재료와 브랜드 메시지를 강조한 메인 비주얼
- 고사리·당근·전복·흑돼지 시그니처 피자 소개
- 전체 메뉴판 팝업
- 함덕 오션뷰 매장과 데이트 경험 소개
- 브랜드 스토리 및 굿즈 이미지
- 네이버 지도 검색과 인스타그램 연결
- 모바일 내비게이션, 스크롤 등장 효과, 접근성 대응

## 디자인

- 감귤 오렌지, 바다 블루, 현무암 블랙의 단색 팔레트
- 제공된 레트로 제주 이미지 자료 활용
- 그라데이션 및 장식용 SVG 미사용
- 데스크톱과 모바일을 지원하는 반응형 레이아웃

## 기술 구성

- HTML5
- CSS3
- Vanilla JavaScript
